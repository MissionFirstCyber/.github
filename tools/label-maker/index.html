First-time print setup
  1. Use Chrome or Edge. They honor the label page size most reliably.
  2. Calibrate the printer to the new roll. Most thermal printers learn the label size when you hold the feed button for 2–3 seconds until it feeds a few labels and beeps. Check your printer's manual. Do this every time you switch roll sizes.
  3. Set the driver paper size to Width 2 in, Height 1 in (50.8 × 25.4 mm). Width means across the print head. If it is set to 1 × 2, or still set to 4 × 6, the printer feeds the wrong length and the label comes out sideways.
  4. In the browser print dialog, set Margins: None, Scale: 100% or Default (not "fit to page"), and turn Headers and footers off. If a Paper size option is shown, pick your 2 × 1 size.
  5. Click Print test label. "TOP" should read normally across a single label, with the tick marks at the middle of each edge. Use the nudge values to center it.
  6. Leave Rotate 90° off unless the test label still prints sideways after the steps above.
  7. Faint print? Raise the darkness or density in the printer driver rather than using grey text.
